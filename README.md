# Personal Finance Manager

## Overview
The **Personal Finance Manager** is a Java-based application designed to help users track their daily financial activities. It allows users to manage their income and expenses securely through a user-friendly console interface. The system ensures data persistence by saving all records to local storage.

## Features
- **User Authentication:** Secure login and registration system.
- **Transaction Management:** Add income and expenses with descriptions.
- **Financial Reporting:** View full transaction history.
- **Real-time Balance:** Automatically calculates current wallet balance.
- **Data Persistence:** All data is saved to `.txt` files and retrieved upon restart.

## Technologies Used
- **Language:** Java (JDK 8+)
- **Concepts:** Object-Oriented Programming (OOP), File I/O, Collections Framework.
- **Tools:** Git, IntelliJ IDEA / Eclipse.
