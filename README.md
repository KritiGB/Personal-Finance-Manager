Personal Finance ManagerOverviewThe Personal Finance Manager is a Java-based application designed to help users track their daily financial activities. It allows users to manage their income and expenses securely through a user-friendly console interface. The system ensures data persistence by saving all records to local storage.FeaturesUser Authentication: Secure login and registration system.Transaction Management: Add income and expenses with descriptions.Financial Reporting: View full transaction history.Real-time Balance: Automatically calculates current wallet balance.Data Persistence: All data is saved to .txt files and retrieved upon restart.Technologies UsedLanguage: Java (JDK 8+)Concepts: Object-Oriented Programming (OOP), File I/O, Collections Framework.Tools: Git, IntelliJ IDEA / Eclipse.How to RunEnsure Java is installed (java -version).Compile the code:javac *.java
Run the application:java Main
Testing InstructionsSelect "Register" to create a new account.Login with your new credentials.Add an Income of 5000.Add an Expense of 200.Select "Check Balance" (Should show 4800).Exit and restart the app to verify data is loaded back.
